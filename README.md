**# 🌿 EcoShield – Chennai Environmental Intelligence Dashboard**



**EcoShield is an interactive environmental intelligence dashboard**

**developed using R Shiny to explore environmental datasets related**

**to Chennai.**



**## Features**



**- 📊 Environmental data overview**

**- 🌧️ Rainfall data visualization**

**- 🗺️ Flood-related geographic visualization**

**- 🌫️ Air quality analysis**

**- 🌳 Parks data exploration**

**- 🌍 Environmental monitoring interface**



**## Technologies Used**



**- R**

**- Shiny**

**- ggplot2**

**- Plotly**

**- Leaflet**

**- dplyr**

**- tidyr**

**- readr**



**## Project Structure**



**- `app.R` – Main Shiny application**

**- `clean\_datasets.R` – Dataset cleaning**

**- `rainfall\_visualization.R` – Rainfall visualizations**

**- `flood\_map.R` – Flood-related geographic visualization**

**- `air\_quality\_visualization.R` – Air quality visualizations**

**- `park\_visualization.R` – Parks data visualizations**

**- `data/` – Project datasets**



**## How to Run**



**1. Install R and RStudio.**

**2. Open `EcoShield.Rproj`.**

**3. Open `app.R`.**

**4. Install any missing required R packages.**

**5. Click \*\*Run App\*\* in RStudio.**



**## Data Limitations**



**Historical datasets and live environmental information must be**

**distinguished clearly. Data availability, observation periods,**

**missing values, and source limitations may affect the results.**
